# 🖼️ Image Search App

A responsive image search application built using **React**, **TypeScript**, and the **Pixabay API**. It features infinite scrolling, loading indicators, smooth animations, and a responsive masonry layout.

---

## 🚀 Features

- 🔍 Search for high-quality images using Pixabay
- 🖼️ Responsive masonry grid layout
- ♾️ Infinite scroll with Intersection Observer
- 🌗 Light UI with subtle animations
- ⚡ Fast loading with lazy-loaded images
- ✅ Built with TypeScript + Tailwind CSS

---

## 📦 Tech Stack

- React + TypeScript
- Tailwind CSS
- Vite
- Pixabay API
- ESLint with TypeScript and React support

---

## 🔧 Setup Instructions

1. **Clone the Repository**
   ```bash
   git clone https://github.com/Bhuvangs04/Image-search-grids.git
   cd image-search-app

2. **Install Dependencies**
   ```bash
   npm install

3. **Add Your Pixabay API Key**
   ```bash
   Create a .env file in the root directory and add
    VITE_PIXABAY_API_KEY=your_pixabay_api_key_here

4. **Start the Development Server**
   ```bash
   npm run dev
